# Frontend Mini Projects

16 small HTML, CSS and JavaScript projects I built to practice frontend development.

**Live site:** https://adejoke234.github.io/frontend-mini-projects/

## About these projects

These projects were built as practice while following frontend tutorials. I customized each one with my own design (colors, fonts and layout) and added at least one new feature to each.

## Projects

| Project | What I added |
| --- | --- |
| 404 Page | Animated 404, random messages, link back home |
| Bookmark Saver | Search box, automatic https, error messages |
| Color Palette Generator | Lock a color, Space key to generate |
| Contact Form | Character counter and success screen |
| Currency Converter | Swap button, error handling |
| Drag and Drop | Kanban board with add, delete and saved state |
| Expense Tracker | Income and expense toggle |
| Form Validator | Show and hide password |
| GitHub Finder | Recent searches |
| Newsletter Signup | Email validation and thank-you state |
| Password Generator | Exclude look-alike characters, secure random |
| Pricing Cards | Monthly and yearly toggle |
| Quiz Game | Timer, shuffle, difficulty levels, 20 questions, best scores |
| Recipe Finder | Favorites |
| Team Members Showcase | Search |
| To-Do App | Double-click to edit |

## Tech

HTML5, CSS3 and JavaScript. No frameworks.
